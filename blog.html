Learning note / robot geometry

One target.
Two ways to reach it.

A robot's end position does not always tell you how its joints are arranged. A two-link arm makes that visible.

Start with a prediction

Imagine two 1 m links joined at an elbow, with the base at the origin. Point the first link along the positive x-axis and turn the second link 90 degrees counterclockwise. The end point is (1,1) m.

Now change the joints, not the target

Turn the first link 90 degrees from the x-axis and set the second joint to -90 degrees relative to the first link. The elbow moves, but the end point is still (1,1) m. Two joint configurations give the same end position.

What this teaches

Forward kinematics maps joint angles to an end position. Working backward from a position can produce more than one solution. A real robot also needs joint limits, collision checks and other constraints before a configuration can be considered usable.

Try it

Use the two-link model to compare (0°,90°) with (90°,-90°). Then set the target to (2,2) m. Its distance from the base exceeds the total link length, so no configuration can reach it.
