Simulation

Robot simulation

Start with a first physics scene, then control an arm and connect a mobile robot to ROS 2.

Before you start

A working NVIDIA Isaac Sim 6.0.1 installation and NVIDIA driver are required by the guides. Lab 3 additionally requires Ubuntu, ROS 2 Humble, RViz2 and Nav2. Read each guide’s required files before starting.

Where you can work

No physical robot is needed for these simulation guides. A compatible computer and software setup are still required.

Available: HTML guides. Some exercises refer to instructor-provided files; check the resource notes below.

  1. Isaac Sim Basic Usage and First Physics Simulation
  2. UR5e Joint and TCP Control in Isaac Sim
  3. TurtleBot 3 ROS2 Integration, Sensors, Localization, and Navigation

Physical robot

Articulated robots

Move from manual operation and drawing to pick-and-place, camera sorting and kinematics.

Before you start

Start with Lab 1. Its materials list includes a Dobot Magician Lite, a computer with DobotLab, USB/power connections and drawing supplies. Later labs introduce Python and camera work.

Where you can work

Read freely from anywhere. Completing the robot exercises requires the stated hardware and a safe, supervised work area.

Available: HTML guides with their original source credits.

  1. Robot Operation, Coordinate Recording, and Drawing
  2. Pick-and-Place with Suction and Gripper End Effectors
  3. Object Detection, Classification, and Sorting
  4. Forward and Inverse Kinematics

Simulation + live cell

Wafer-cell digital twin

Read the introduction and safety reference first, then follow Labs 1–6 in order.

Before you start

The introduction calls for basic Python and Linux. It contains the reference environment, ROS 2 Jazzy, Gazebo/Isaac Sim setup, a glossary and the read-only connection rules. Individual labs list their own requirements.

Where you can work

Some sections use recordings or desk tests; live validation uses the physical wafer cell. This is not a promise that every lab can be completed remotely. Never command the cell from the twin.

Available: HTML guides, local PDF manuals, plus the author’s linked code and course-data release.

  1. Digital Twin Labs: Introduction, Safety and Reference
  2. Lab 1: Reading the Cell: The Read-Only Bridge
  3. Lab 2: Building the Live Digital Twin
  4. Lab 3: Wafer Handling with Contact Physics
  5. Lab 4: Vision Trained in Simulation
  6. Lab 5: Fault Detection from Motion
  7. Lab 6: Making the Real Cell Faster with the Twin

Physical workcell · PDF guides

IIoT workcell

Follow the cell build from power and network through both robots, sequencing and SCADA.

Before you start

Begin with Lab 1’s power, safety and network guide. These guides use the physical workcell, PLC, robots and associated software. Each original PDF gives its own setup and equipment details.

Where you can work

The PDFs can be studied away from the lab. Building and operating the workcell requires the actual equipment, local safety procedures and supervision.

Available: Short HTML entry pages and the author’s original downloadable PDF guides.

  1. Cell Power, Safety and Network
  2. Dobot M1 Pro: Network, Teaching and Bridge
  3. myCobot Pro 600: Network, Vacuum and Bridge
  4. Conveyor, Sensors and Laser Station
  5. Sequencer and Vision
  6. SCADA Dashboard and Data Logging

Project briefs · physical systems

RAS 545 project briefs

Explore camera-assisted tic-tac-toe, vision-guided maze solving and agentic manipulation.

Before you start

Read each full brief for its system requirements and supplied files. These are course assessments, not a new externally graded course.

Where you can work

Read the briefs and inspect supplied materials freely. Physical execution requires suitable equipment and supervision; external access does not include course enrollment or assessment.

Available: HTML briefs, assignment PDFs and the supplied maze starter-code archive.

  1. Camera-Assisted Tic-Tac-Toe Robot
  2. Vision-Guided 4 × 4 Maze Solving
  3. Agentic Physical AI Manipulation

Resources to check before starting

Isaac Sim Lab 2 refers to a controller module whose download reference is not yet resolved here. Lab 3 also refers to instructor-provided scene and map files. Check the guide and confirm you have those files before beginning; a link to a lesson does not mean every required input is included.

The digital-twin introduction links to the author’s code repository and course-data release. Those external resources retain their own terms and version requirements.

Credits, reuse and safety

Free reading access is not a blanket license to copy, adapt or redistribute. Keep the author credits and follow the terms attached to each resource. Where no reuse license is stated, seek permission from the relevant rights holder. Linked software, figures and manufacturer materials may have separate terms.

These guides describe specific equipment and reference environments. Do not infer compatibility with another setup. Follow each guide’s safety instructions and your institution’s local procedures before operating hardware.
